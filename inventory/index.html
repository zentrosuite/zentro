What Zentro Inventory is

Billing software that actually keeps the books

Most billing apps print an invoice and stop there. The stock figure drifts, the profit number is a guess, and at the end of the year somebody reconciles it by hand.

📦

One record for stock

Every movement is appended to a stock ledger that is never edited. Quantities on hand are a cache derived from it — and they can be rebuilt from scratch at any time.

⚖️

One record for money

Every rupee lands as a balanced double entry. A correction is a reversing entry, never a silent edit, so last March's balance sheet still reads the same today.

🧾

One record for intent

Invoices, bills and returns are the business record. A draft moves nothing at all; only a confirmed document touches stock or the ledger.

Questions

Straight answers

Is Zentro Inventory really free?

The free build is genuinely free and does not expire — one user, one counter, one location, with GST invoicing, point of sale, stock and the core reports. It is not a trial. Growing past a single counter, or wanting barcode labels, custom templates, scheduled backups or the full report set, needs the Business licence — a one-time fee, not a subscription.

Do I get the source code?

No. Zentro Inventory is delivered as an encrypted build that you install and run on your own machine. You own yourdatacompletely — it is a normal MySQL database you can back up, read and take elsewhere at any time — but the application code itself is licensed, not open source, and that is true of every plan including Managed hosting.

What do I need to run it?

A machine with PHP 8.4 and MySQL 8 — a basic VPS, an office desktop or a shop computer is plenty. There is a setup wizard: point a web server at the folder, open it in a browser and it walks you through creating the database, the tables and your owner account.

Does it work without the internet?

Yes. It is a normal web application served from your own machine, so a browser on the same network reaches it whether or not the internet is up. Only optional extras — emailing a bill, sending it on WhatsApp — need a connection.

Is it GST compliant?

Tax is calculated per line and stored per line, split into CGST/SGST or IGST from the place of supply. The GST summary gives you output tax, input credit and net payable, rate-wise and HSN-wise, with B2B and B2C separated and credit notes as CDNR. Composition suppliers correctly charge no GST, and blocked credit is kept out of the claim.

Can more than one person use it at once?

Yes — unlimited users. Roles set what each of them can reach, and you can allow or deny an individual user a single page on top of their role. A new user sets their own password the first time they sign in.

What happens to my data if I stop using Zentro?

Nothing. It is your MySQL database on your machine. Take a backup from the Backups screen and you have a plain SQL dump inside a zip that any developer or accountant can read.

Does it handle multiple shops or warehouses?

Stock is tracked per warehouse, with transfers between them, and the point of sale is tied to the location it sells from. Reports can be read per warehouse or across all of them.

Can it print barcodes and work with a scanner?

Yes. Any USB barcode scanner works — it types into the search box like a keyboard. Labels print as EAN-13 or Code 128 on A4 sheets or thermal rolls, laid out in millimetres so the printed width is what the scanner expects.

What about HRMS and CRM?

They are on the way under the same Zentro brand and will share the look, the login and the data model. Inventory is the one that is finished and shipping today — we would rather ship one thing properly than four things half-built.
