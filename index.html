The platform underneath

One platform, not ten tools that happen to share a logo.

Suites usually turn out to be acquisitions with a shared invoice. Zentro is the opposite: one codebase, one database, one permission model — and every app is a module on top of it.

  • One identity, one permission model Add a person once and grant them screens across any app. Roles set the baseline; individual pages can be allowed or denied on top.
  • One record for each thing A customer, an employee, an item, a rupee. Entered once, read everywhere — so nothing is re-typed and nothing quietly drifts apart.
  • One interface to learn The same layout, the same keyboard shortcuts, the same print stack. Learn one app and you have most of the way learnt all ten.
  • One install to run PHP and MySQL on a machine you control. Add an app to the suite and it joins the same install, the same backup and the same login.

Why Zentro

Built like accounting software, not like an app

The decisions below are the ones you feel three years in — when the subscription renews, when the auditor asks, and when the internet goes down mid-sale.

Your server, your data

Zentro installs on a machine you control — a VPS, an office desktop, a shop computer. Your sales history is a MySQL database in your building, not a row in someone else's tenant.

Licensed once, never monthly

Buy the licence and it is bought. No per-seat pricing, no annual increase, and nothing that stops working the month you decide to stop paying.

Nothing is silently edited

Stock movements and journal entries are append-only. A mistake is corrected by a reversing entry, so last March's balance sheet still reads the same today.

Made for Indian compliance

GST worked out per line and stored per line, HSN summaries, B2B and B2C splits, place of supply, composition and blocked ITC — not a tax field bolted onto an American product.

Keeps working offline

It is served from your own machine, so a browser on the same network reaches it whether or not the line is up. Only email and WhatsApp need the internet.

Fast, and reachable by everyone

Keyboard-first screens, real focus states, honest colour contrast and a dark mode that is designed rather than inverted — in every app, not just the marketing site.

Questions

Straight answers

What exactly is Zentro?

A family of business applications built on one shared platform: inventory, CRM, HR, events, surveys, accounting, expenses, payroll, notes and tables. They share a login, a database and a design, and they install on hardware you control rather than running as a service somebody else operates.

Which apps can I actually use today?

One — Zentro Inventory. It is finished, installed in real businesses and supported. Every other app on this page is labelled Coming soon because it genuinely is: some are in development, some are still in design. We publish the order we are building in rather than a wall of launch dates.

When will the rest ship?

CRM and HRMS are in development; Books, Expense and Payroll are in design; Backstage, Survey, Notebook and Tables are scoped and planned. We will not put a date on any of them until it is a date we can keep. If one of them is what you need, tell us — that genuinely moves it up the list.

Is Zentro cloud software or self-hosted?

Self-hosted by default. You install it on a VPS, an office desktop or a shop computer running PHP 8.4 and MySQL 8, and there is a setup wizard that creates the database and tables for you. If you would rather not run a server, our Managed hosting plan runs the same software for you — with the data still exportable at any time.

How is it priced?

Per app, in three shapes: a free build that never expires, a one-time licence that unlocks everything on your own server, and monthly managed hosting if you want us to run it. There is no per-seat charge and no renewal — a bought licence stays bought.

Do the apps really work together, or is that marketing?

They share the platform, not just the brand: one user table, one permission model, one ledger, one reporting engine. A customer created at the counter in Inventory is the same record CRM will follow up; an employee in HRMS is the one Payroll pays. That is the whole reason we are building them in order instead of all at once.

Do I get the source code?

No. Zentro apps are delivered as an encrypted build you install and run yourself. You own your data completely — it is a normal MySQL database you can back up, read and take elsewhere at any time — but the application code is licensed rather than open source, on every plan including Managed hosting.

Can I move over from Tally, a spreadsheet or another package?

Usually, yes. Products, opening stock, customers, suppliers and outstanding balances import from CSV, and migration is included in the Suite licence — we do the first load with you rather than handing over a template and wishing you luck.

What happens to my data if I stop using Zentro?

Nothing. It is your MySQL database on your machine. Take a backup from the Backups screen and you have a plain SQL dump inside a zip that any developer or accountant can read — no export request, no waiting period.
